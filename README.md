# Supermarket Sales Dashboard

## Project Overview

This project analyzes supermarket sales data using SQL, Excel, and Power BI.

## Tools Used

- SQL
- Excel
- Power BI
- DAX

## 📊 Dashboard Features

### 🔹 Executive KPI Overview
- **Total Investment** – Provides a high-level view of the overall investment.
- **Total Sales** – Tracks overall sales revenue generated.
- **Total Quantity** – Monitors the total number of units sold.
- **Total Profit** – Measures overall profitability.

### 🔹 Interactive Business Analysis
- **City-wise Sales Analysis** – Compares sales performance across Mandalay, Naypyitaw, and Yangon.
- **Product Line Performance** – Evaluates sales across different product categories.
- **Gender-wise Sales Distribution** – Analyzes sales contribution by customer gender.
- **Monthly Sales Trend** – Tracks sales performance across months and identifies changes in sales patterns.

### 🔹 Interactive Filters
- **City**
- **Product Line**
- **Gender**

These slicers allow users to dynamically filter the dashboard and perform focused analysis.

### ⭐ Key Highlights
- Interactive KPI-driven dashboard for quick performance monitoring.
- Multi-dimensional analysis across **City, Product Line, Gender, and Time**.
- Clear visualization of sales and profitability metrics.
- Dynamic filtering for targeted business analysis.
- Designed to support **data-driven decision-making**.

5. SQL Analysis

SQL was used to explore the supermarket dataset, calculate key business metrics, and identify sales and customer trends.

### 🔍 Analysis Performed

- Calculated the total number of records in the dataset.
- Counted the total number of columns in the dataset.
- Calculated total sales revenue.
- Calculated total profit.
- Calculated total investment using buying price.
- Analyzed city-wise sales and investment.
- Analyzed branch-wise investment.
- Analyzed gender-wise sales performance.
- Analyzed product-line-wise sales performance.
- Identified the product line with the highest quantity sold.
- Calculated average rating for each product line.
- Categorized customer ratings into Excellent, Good, and Average.
- Counted customers with ratings greater than or equal to 9.
- Analyzed sales generated by Yangon city.
- Used `GROUP BY`, `HAVING`, `ORDER BY`, `CASE`, aggregate functions, and date functions for analysis.
- Performed monthly sales analysis using date conversion and `STR_TO_DATE()`.

### 📊 Key SQL Metrics

| Analysis | SQL Function / Concept |
|---|---|
| Total Sales | `SUM()` |
| Total Profit | `SUM()` |
| Total Investment | `SUM()` |
| Number of Records | `COUNT()` |
| City-wise Sales | `GROUP BY` |
