# 📊 Supermarket Sales Dashboard

## 📌 Project Overview
This project analyzes supermarket sales data using SQL, Microsoft Excel, Power BI, Tableau, and DAX. It provides an interactive dashboard to monitor sales performance, profit, customer behavior, product performance, and branch-wise analysis for better business decision-making.

---

## 🛠️ Tools & Technologies Used
- SQL (MySQL)
- Microsoft Excel
- Power BI
- Tableau
- DAX (Data Analysis Expressions)

---

## 📂 Dataset
- Supermarket Sales Dataset (.csv)

---

## 📈 Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Investment
- Total Quantity

---

## 📊 Dashboard Features
- Sales by Product Line
- Sales by Branch
- Sales by Customer Type
- Sales by Payment Mode
- Monthly Sales Trend
- Interactive Slicers
- KPI Cards

---

## 🔍 Key Insights
- Identified the best-performing product lines.
- Compared sales across different branches.
- Analyzed customer purchasing patterns.
- Evaluated payment mode preferences.
- Tracked monthly sales performance.
- Monitored overall business performance using KPI metrics.

### 📊 Key SQL Metrics

| Analysis | SQL Function / Concept |
|---|---|
| Total Sales | `SUM()` |
| Total Profit | `SUM()` |
| Total Investment | `SUM()` |
| Number of Records | `COUNT()` |
| City-wise Sales | `GROUP BY` |
| Product Line Sales | `GROUP BY` |
| Branch Investment | `GROUP BY` |
| High Investment Cities | `HAVING` |
| Highest / Lowest Sales | `MAX()`, `MIN()` |
| Average Product Rating | `AVG()` |
| Rating Categories | `CASE` |
| Monthly Sales | `STR_TO_DATE()`, `DATE_FORMAT()` |
| Top Product Line | `ORDER BY`, `LIMIT` |
