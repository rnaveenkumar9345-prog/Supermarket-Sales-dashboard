# Supermarket Sales Dashboard

## Project Overview

This project analyzes supermarket sales data using SQL, Excel, and Power BI.

## Tools Used

- SQL
- Excel
- Power BI
- DAX

## Dashboard Features

- KPI Cards
- Sales by City
- Sales by Product Line
- Gender Analysis
- Monthly Sales Trend
- Interactive Slicers

## Business Insights

- Identified top-selling product categories.
- Compared sales across cities.
- Analyzed customer demographics.
- Visualized monthly sales performance.
